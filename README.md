# National Digital Auto Testing

מדריך אינטראקטיבי לתרגול שאלות בדיקות אוטומציה.

## נושאים
- API Testing (gov.il GET request)
- Cypress command queue
- Java GCD algorithm

## תוצאות בדיקות
- `results/postman/` — תוצאות Postman Collection Run
- `results/cypress/` — screenshots ודוחות Cypress

## מבנה הפרויקט
```
├── index.html          # מדריך HTML אינטראקטיבי
├── docs/
│   └── exam.pdf        # בחינה מקצועית (מקור)
├── results/
│   ├── postman/        # תוצאות Postman
│   └── cypress/        # תוצאות Cypress
```

## הפעלה
פתח את `index.html` בדפדפן, או צפה דרך [GitHub Pages](https://maya5768.github.io/nationalDdigitalAutoTesting/).
